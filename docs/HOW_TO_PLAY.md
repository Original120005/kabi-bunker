# Как запустить игру с друзьями

Сервером служит ваш компьютер. Друзья заходят по ссылке из браузера — на телефоне или ПК, ничего не устанавливая.

## Первый запуск (один раз)

Нужен Node.js 22 или новее (`node -v`). Откройте PowerShell в папке `bunker-online` и выполните:

```powershell
npm install
```

## Каждая игра

```powershell
npm run play
```

Команда сама:
1. собирает клиент;
2. делает копию базы в `data/backups/` (хранятся последние 10);
3. обновляет базу и добавляет новый контент из `content/packs/`;
4. запускает сервер на `http://localhost:3000`;
5. поднимает туннель Cloudflare. При первом запуске скачивается `cloudflared` (~60 МБ) в `tools/bin/`.

Когда всё готово, появится рамка со ссылкой вида `https://слова-через-дефис.trycloudflare.com`. Её нужно отправить друзьям.
Сами вы можете играть по той же ссылке или по `http://localhost:3000`.

Остановить игру: `Ctrl+C` в окне PowerShell. Пока окно открыто, а компьютер не спит, игра работает.

### Как проходит партия

1. Откройте ссылку, введите ник и нажмите «Создать игру».
2. В лобби скопируйте ссылку на комнату и отправьте друзьям. Она уже содержит адрес туннеля.
3. Когда соберётся 6–15 игроков, нажмите «Начать игру». Все подтверждают готовность, и вы запускаете партию.
4. Если кто-то закрыл вкладку или потерял связь, пусть просто откроет ту же ссылку: он вернётся к своему персонажу.

## Игра без интернета (одна Wi-Fi сеть)

```powershell
npm run play:lan
```

Будут выведены адреса вида `http://192.168.x.x:3000`. При первом запуске Windows спросит разрешение для Node.js
в брандмауэре. Разрешите доступ для **частных сетей**.

## Частые вопросы

**Ссылка не открывается.** Скрипт показывает ссылку только после того, как она появилась в DNS. Если у кого-то из друзей
всё равно ошибка, подождите минуту и обновите страницу. Ссылка меняется при каждом запуске `npm run play`, поэтому
старые ссылки не работают.

**Компьютер перезагрузился посреди партии.** Запустите `npm run play` снова: комнаты восстановятся из базы. Ссылку туннеля
нужно разослать заново (код комнаты останется прежним).

**`npm install` пишет `EPERM ... query_engine-windows.dll.node`.** Запущенный сервер держит файл базы данных. Остановите
игру (`Ctrl+C`) и повторите команду.

**Хочу постоянную ссылку.** Нужен свой домен на бесплатном аккаунте Cloudflare и именованный туннель. Код менять не нужно,
меняется только настройка туннеля.

## Свой контент

Паки лежат в `content/packs/<имя>/`:
- `pack.json` — название и приоритет пака;
- `definitions.json` — характеристики и поля бункера;
- `items/*.json` — элементы: `{ "type": "hobby", "items": [{ "title": "Рыбалка" }] }`.

Новые элементы попадают в базу при следующем `npm run play`. Элементы, которые уже есть в базе, не перезаписываются,
чтобы не потерять правки из редактора (он появится на этапе 6). Применить правки из JSON к существующим элементам:

```powershell
npm run seed:update
```

## Для разработки

```powershell
npm run dev        # сервер на :3000 и клиент с горячей перезагрузкой на http://localhost:5173
npm test           # тесты движка и контента
npm run typecheck  # проверка типов
node scripts/smoke.mjs http://localhost:3000 7   # сквозная проверка на запущенном сервере
```

Перед первым `npm run dev` нужна база: выполните `npm run play` один раз или `npm run db:migrate` и `npm run seed`.
